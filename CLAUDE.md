## Технологии и команды

C# **5**, WinForms, .NET Framework **4.8**, Windows x64. Компилятор — штатный `csc.exe` из Windows. NuGet, Python, Node.js и .NET SDK для основной сборки не нужны. Linux/macOS не воспроизводят Windows GUI и нативную сборку этим скриптом.

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1 -Test
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\Package.ps1
```

Готовый EXE находится в `bin/`, ZIP и SHA-256 — в `dist/`. `Start.cmd` запускает локальную сборку. Если EXE из `bin` открыт, компилятор не сможет его перезаписать: сначала закрой именно русификатор обычным способом.

Используй Windows PowerShell **5.1** (`powershell.exe`), а не `pwsh`: библиотека System.Web.Extensions здесь относится к .NET Framework. Не добавляй современный синтаксис C# без осознанного изменения системы сборки; например, await в catch не поддерживается C# 5.

## Главные правила проекта

1. Оригинальный `app.asar` сохраняется неизменяемым и проверяется по SHA-256. Никогда не подставляй старую сборку вместо новой по одному номеру версии.
2. Меняется только `resources/app.asar`. Не меняй EXE, Language Server, Electron fuses, DNS, прокси и настройки безопасности ради перевода.
3. Проверка подписи ASAR должна приводить к отказу, если она включена. Не отключай защиту.
4. Сохраняй пользовательское содержимое: тексты чатов, код, Markdown, терминал, имена файлов и значения ввода не переводятся.
5. Не завершай Antigravity принудительно. Запись разрешена только после проверки, что целевая установка закрыта.
6. Не добавляй оригинальные архивы/бинарники Antigravity, реальные профили, токены, логи или резервные копии в Git и публичные Releases.
7. Отчёт для Telegram собирается из разрешённых полей; не копируй в него сырые исключения, личные пути и журнал UI. Отправку подтверждает пользователь в Telegram.
8. Нельзя обещать поддержку всех будущих версий. Совместимость структуры — эвристика; новый интерфейс может потребовать пересмотра селекторов.

## Изменение перевода и выпуск

Источник словаря — `payload/dictionary.json`, источник DOM-слоя — `payload/localize-ui.template.js`. `localize-ui.js` генерируется `Sync-Payload.ps1`; Build вызывает синхронизацию сам. Не редактируй только сгенерированный файл.

При выпуске меняются версия сборки в `src/Program.cs`, версия по умолчанию в `Package.ps1`, CHANGELOG и статус README. UI берёт версию из AppInfo. Публикуй ZIP с именем `AntigravityRussian-X.Y.Z-win-x64.zip`: автообновление ожидает это имя, стабильный тег, digest GitHub и фиксированный список файлов ZIP. Согласовывай изменение Package и UpdateService.

Выпущенные теги не переписываются. После изменения кода запускай уместные проверки; после документации не требуется повторный GUI-прогон без причины. Сборку и проверки также запускает GitHub Actions на Windows.
