# Устройство

## Исполняемый файл

WinForms-приложение для .NET Framework 4.8, x64. Три ресурса (`dictionary.json`, `localize-ui.js`, `native-rules.json`) встроены в сборку. Секретов, пользовательских путей и исходных бинарных файлов Antigravity в ресурсах нет.

`PatchService` отделён от UI. Длительные операции выполняются в рабочем потоке; кнопки блокируются, закрытие окна во время операции откладывается. UI не завершает процессы Antigravity принудительно. На время изменений используется общий с прежним скриптом mutex текущего сеанса Windows.

## Состояния

1. **Исходная установка** → просмотр и резервное копирование без изменения приложения.
2. **Копия готова** → русификация становится доступна в UI.
3. **Русификация установлена** → доступны проверка копии, запуск и восстановление оригинала.
4. **Неизвестная русификация** → установка блокируется; предлагается импорт точной поддерживаемой старой копии.

Идентификатор установки вычисляется из нормализованного абсолютного пути. Записи внутри установки определяются SHA-256 оригинального архива, а не только номером версии. Перенос копий между установками автоматически не выполняется.

Оригинал сначала копируется во временную папку, проверяется, затем папка переименовывается в окончательную. Уже сохранённый оригинал не перезаписывается. Для установки создаётся файл рядом с `app.asar`, повторно проверяются источник, целевой архив, EXE и состояние процесса. Замена `File.Replace` атомарна; до проверки результата сохраняется аварийная копия предыдущего файла. После успешной проверки она удаляется, постоянный оригинал остаётся.

## Совместимость ASAR

Читаются заголовок pickle, JSON-дерево, packed/unpacked-флаги и ссылки. Проверяются границы данных и существующая SHA-256 integrity, включая блоки. При сборке пересчитываются смещения и хеши изменённых записей. После записи архив повторно читается; список записей и содержимое каждого упакованного файла сравниваются с ожидаемыми байтами.

Обязательные признаки: `name=antigravity`, `productName=Antigravity`, `main=dist/main.js`, упакованный `dist/preload.js`, его использование другим модулем и знакомая CommonJS/Electron-структура preload. Это эвристика совместимости, а не доказательство поддержки произвольной будущей версии.

Перед установкой читаются метаданные Electron fuses в EXE. Если встроенная проверка подписи ASAR включена или формат неизвестен, операция прекращается. EXE и флаги не меняются. Проверки подписи издателя обновлений Antigravity не обходятся.

## Слой перевода

Добавляется к preload в изолированном мире. Включается только в верхнем окне на localhost/127.0.0.1. MutationObserver переводит известные подписи и атрибуты, сохраняя идентичность DOM-узлов. Отдельные регулярные выражения обрабатывают таймеры, лимиты и некоторые динамические подписи. Пользовательское содержимое исключается через защитные селекторы.

Ответ агента (`role="article"`, `aria-label="Agent response"`) защищён целиком, кроме служебных элементов: внутри него переводятся только точные подписи из `chat-labels.json` и шаблоны шагов, разрешений и вопросов. Элементы Markdown-текста (`p`, `li`, заголовки, таблицы, ссылки, выделение), код и имена файлов пропускаются. Сообщение пользователя не переводится. В manifest копии хранится `PayloadSha256`: кэш `russian.asar` от другой версии перевода пересобирается из оригинала.

Нативные меню и диалоги переводятся заменой точных известных фрагментов. Их действия, ID, сочетания клавиш и состояния не меняются. Неузнанные необязательные подписи пропускаются с записью в manifest. Обновление фронтенда может потребовать пересмотра защитных селекторов; после обновления рекомендуется проверить основные разделы.

## Проверки

`Build.ps1 -Test` запускает тесты на небольших независимых ASAR-фикстурах, в том числе для разных сборок с одинаковой версией. Проверяются: идемпотентность, побайтовый откат, сохранение записей, точный Unicode, повреждение копии, новая версия, неизвестная архитектура, сигнатурная защита Electron, неизвестный слой перевода и одновременные операции.

Реальная установленная сборка 2.26.0 использовалась отдельно для проверки структуры, переноса уже существующей копии и UI. Реальные архивы не нужны тестам и не публикуются.

## Поиск установки

Сохранённый путь проверяется первым. Затем рассматриваются работающие процессы Antigravity, типовые каталоги профиля и Program Files, App Paths и Uninstall-записи в HKCU/HKLM для 32/64 бит. Каждый кандидат проходит проверку структуры пакета. Недоступные и устаревшие пути пропускаются, записи реестра не изменяются. Рекурсивного сканирования дисков нет; ручной выбор остаётся доступен.

## Обновление русификатора

По кнопке или при запуске (раз в сутки, если не выключено в настройках) запрашивается публичный GitHub API `/repos/ZakitKH0000/antigravity-russian/releases/latest`. Принимаются стабильные релизы с известным названием ZIP и SHA-256 digest из метаданных GitHub. Размер ограничен 32 МБ. Адрес загрузки привязан к нашему репозиторию и тегу; конечные HTTPS-хосты ограничены GitHub/CDN. Проверяются все имена ZIP, отсутствие повторов и обхода каталогов, размер, digest, имя сборки и версия EXE. Хеш подтверждает целостность загрузки из GitHub, но не является цифровой подписью издателя.

Подготовленный EXE копируется как `Updater.exe` в отдельный GUID-каталог `%LOCALAPPDATA%\AntigravityRussian\updates`. Тот же EXE обрабатывает внутренний аргумент `--finish-update`. Проверяется каталог плана, собственный хеш, исходные файлы и хеш прежнего EXE. Вспомогательный процесс ждёт закрытия прежнего окна до 30 секунд, заменяет EXE и конфигурацию и запускает новую версию. При ошибке замены восстанавливаются предыдущие файлы. Копия прежнего русификатора остаётся в каталоге обновления. Хранилище резервных копий Antigravity не затрагивается.

Сбой сети или недостаток прав не включает повышенные привилегии автоматически; пользователю предлагается ручной ZIP. В 1.0.x механизма обновления нет, поэтому начальный переход на 1.1.0 выполняется вручную.

## Окно, правило агента, один EXE и анлокер (1.2.0)

Главная кнопка выбирается по состоянию `Installation`: русификация (с автоматической копией), «Обновить перевод» (`TranslationOutdated`: `PayloadSha256` записи отличается от встроенного; `UpdateTranslation` под одной блокировкой восстанавливает оригинал и применяет текущий словарь), открытие Antigravity или импорт. `EarlierBuild` означает, что для этой установки есть записи только других сборок, то есть Antigravity обновился.

С 1.3.0 главная кнопка вызывает `PatchService.Russify` (под той же блокировкой): `AntigravityProcesses.Close` закрывает процессы из папки установки (`CloseMainWindow`, через 5 с `Kill`), затем русификатор ждёт установщик обновления, ставит скачанное обновление из `pending` (`--updated /S`, только с подписью Google LLC), заменяет неизвестный перевод и применяет свой. `Installation.WasRunning` говорит окну открыть Antigravity снова. «Вернуть английский» — `RestoreOriginal` с тем же закрытием. Неизвестный перевод заменяется на оригинал, найденный `FindOriginal` (архивы рядом с `app.asar`, записи русификатора, `original.asar` прежнего скрипта в «Документах», на рабочем столе и в «Загрузках»; ограниченный обход) и подтверждённый `AgRuArchive.DerivedFrom`: та же версия, все записи, кроме пяти скриптов перевода, совпадают байт в байт, а `dist/preload.js` начинается с исходного. Иначе `AntigravityUpdater.Latest` читает `latest-x64-win.yml` с сервера из `app-update.yml`, `Fetch` скачивает установщик только с `storage.googleapis.com/antigravity-public/` или `dl.google.com` и сверяет размер и SHA-512, `Install` проверяет подпись (`Signature`: WinVerifyTrust и подписант Google LLC) и запускает установку поверх.

Antigravity обновляется через electron-updater: установщик скачивается в `%LOCALAPPDATA%\<updaterCacheDirName>\pending` (имя каталога — из `resources/app-update.yml`) и запускается при выходе из приложения, возвращая английский `app.asar`. `AntigravityUpdater` считает процессы, запущенные из этого каталога: окно ждёт и их, а `EnsureClosed` отказывает в записи, пока они работают. `UpdatePending` — установщик в `pending` новее установки; время установки берётся из времени создания `Antigravity.exe` и изменения корневой папки, потому что установщик сохраняет время сборки файлов. Окно перепроверяет установку при активации и перед отчётом. `AppFolder` — существует `resources/app/package.json`: Electron загружает эту папку раньше `app.asar`, поэтому русификация отклоняется с объяснением.

`DesktopShortcut` создаёт `Русификатор Antigravity.lnk` через WScript.Shell (позднее связывание) и меняет или удаляет только ярлык, чьё описание начинается с маркера `Antigravity Russian`.

Правило языка агента — Markdown-файл с `trigger: always_on` в глобальном корне настроек Antigravity `~/.gemini/config/rules/`. Домашняя папка берётся из `USERPROFILE`, как у `os.UserHomeDir` в language server. Файл помечен комментарием-маркером; удаляется и перезаписывается только файл с этим маркером. Настройки русификатора (`settings.json` рядом с копиями): проверка обновлений при запуске (не чаще раза в 20 часов) и предпочтение правила.

`App.config` встроен в EXE. Если рядом нет `.exe.config`, `Program` до первого чтения настроек записывает встроенный файл во временную папку и подключает его через `APP_CONFIG_FILE`: режим высокого DPI WinForms остаётся включённым. ZIP релиза сохраняет EXE и конфигурацию для встроенного обновления прежних версий.

Совместимость с анлокером confeden/Antigravity (`RegionalUnlocker`): анлокер распаковывает `app.asar` в `resources/app`, если `dist/main.js` не похож на оболочку 2.4+ (`./languageServer` и `./ipcHandlers` без старого кода авторизации). Перед установкой собранный архив проверяется тем же условием; если оригинал ему соответствовал, а перевод нет, операция отменяется. Анлокер меняет только `language_server`/`agy`, NRPT и свою службу; `AG_LS_PROXY` читается лишь для подсказки о неработающей службе.

## Отчёт и Telegram

В памяти текущего сеанса сохраняются до 12 событий: код действия из фиксированного списка и имя типа исключения, без его сообщения и stack trace. Добавляются версии, Windows и булевы признаки установки. Строка версии внешнего пакета допускается только при успешном Version.TryParse. В отчёт не копируются журнал UI, пути, учётные данные и содержимое файлов.

Пользователь видит предпросмотр и отдельно выбирает копирование, TXT или открытие `https://t.me/zak0407?text=...`. Последнее передаёт показанный текст в ссылке для черновика; это действие выполняется только после нажатия. Кнопка отправки остаётся в Telegram. Формат ссылки основан на [официальной документации Telegram](https://core.telegram.org/api/links#public-username-links). Бот и фоновая отправка отсутствуют.
