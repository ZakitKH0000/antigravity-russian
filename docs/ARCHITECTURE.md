# Устройство

## Исполняемый файл

WinForms-приложение для .NET Framework 4.8, x64. Три ресурса (`dictionary.json`, `localize-ui.js`, `native-rules.json`) встроены в сборку. Секретов, пользовательских путей и исходных бинарных файлов Antigravity в ресурсах нет.

`PatchService` отделён от UI. Длительные операции выполняются в рабочем потоке; кнопки блокируются, закрытие окна во время операции откладывается. UI не завершает процессы Antigravity принудительно. На время изменений используется общий с прежним скриптом mutex текущего сеанса Windows.

## Состояния

1. **Исходная установка** → просмотр и резервное копирование без изменения приложения.
2. **Копия готова** → русификация становится доступна в UI.
3. **Русификация установлена** → доступны проверка копии, запуск и восстановление оригинала.
4. **Неизвестная русификация** → установка блокируется; предлагается импорт точной поддерживаемой старой копии.

Идентификатор установки вычисляется из нормализованного абсолютного пути. Записи внутри установки определяются SHA-256 оригинального архива, а не только номером версии. Перенос копий между установками автоматически не выполняется.

Оригинал сначала копируется во временную папку, проверяется, затем папка переименовывается в окончательную. Уже сохранённый оригинал не перезаписывается. Для установки создаётся файл рядом с `app.asar`, повторно проверяются источник, целевой архив, EXE и состояние процесса. Замена `File.Replace` атомарна; до проверки результата сохраняется аварийная копия предыдущего файла. После успешной проверки она удаляется, постоянный оригинал остаётся.

## Совместимость ASAR

Читаются заголовок pickle, JSON-дерево, packed/unpacked-флаги и ссылки. Проверяются границы данных и существующая SHA-256 integrity, включая блоки. При сборке пересчитываются смещения и хеши изменённых записей. После записи архив повторно читается; список записей и содержимое каждого упакованного файла сравниваются с ожидаемыми байтами.

Обязательные признаки: `name=antigravity`, `productName=Antigravity`, `main=dist/main.js`, упакованный `dist/preload.js`, его использование другим модулем и знакомая CommonJS/Electron-структура preload. Это эвристика совместимости, а не доказательство поддержки произвольной будущей версии.

Перед установкой читаются метаданные Electron fuses в EXE. Если встроенная проверка подписи ASAR включена или формат неизвестен, операция прекращается. EXE и флаги не меняются. Проверки подписи издателя обновлений Antigravity не обходятся.

## Слой перевода

Добавляется к preload в изолированном мире. Включается только в верхнем окне на localhost/127.0.0.1. MutationObserver переводит известные подписи и атрибуты, сохраняя идентичность DOM-узлов. Отдельные регулярные выражения обрабатывают таймеры, лимиты и некоторые динамические подписи. Пользовательское содержимое исключается через защитные селекторы.

Нативные меню и диалоги переводятся заменой точных известных фрагментов. Их действия, ID, сочетания клавиш и состояния не меняются. Неузнанные необязательные подписи пропускаются с записью в manifest. Обновление фронтенда может потребовать пересмотра защитных селекторов; после обновления рекомендуется проверить основные разделы.

## Проверки

`Build.ps1 -Test` запускает тесты на небольших независимых ASAR-фикстурах, в том числе для разных сборок с одинаковой версией. Проверяются: идемпотентность, побайтовый откат, сохранение записей, точный Unicode, повреждение копии, новая версия, неизвестная архитектура, сигнатурная защита Electron, неизвестный слой перевода и одновременные операции.

Реальная установленная сборка 2.26.0 использовалась отдельно для проверки структуры, переноса уже существующей копии и UI. Реальные архивы не нужны тестам и не публикуются.
