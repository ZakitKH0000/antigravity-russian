# Передача проекта Claude

Срез состояния: **27 октября 2026 года**, версия продукта **1.1.0**. Этот документ сохраняет контекст разработки, а не назначает новую задачу. После чтения уточняй следующую задачу у владельца, если она не указана в его текущем сообщении.

## Что хотел пользователь и что уже сделано

Сначала потребовалось перевести установленный Antigravity на русский с возможностью полного отката. Были подготовлены локальный скрипт и словарь, затем выполнен обход доступных разделов и статический просмотр ресурсов. Некоторые серверные подписи добавлялись отдельно.

После этого пользователь попросил полноценное приложение, которое можно передать брату и другим людям. Проект вынесен в отдельную папку на рабочем столе, создан публичный GitHub. Затем добавлены самообновление русификатора, расширенный автопоиск, отчёт разработчику и Telegram автора. Пользователь также попросил явно отделить перевод интерфейса от регионального анлокера и проверить полный путь нового пользователя.

Завершённые возможности:

- графический интерфейс с выбором установки, копией, русификацией, запуском и откатом;
- отдельные оригиналы каждой сборки, включая разные хеши при одинаковом номере версии;
- восстановление после повреждения производного русского кэша без потери оригинала;
- поиск сохранённого пути, процессов, типовых папок, HKCU/HKLM App Paths и Uninstall для 32/64 бит;
- ручной выбор, если поиск не удался;
- стабильные обновления самого русификатора через GitHub, digest, ZIP-проверки и отдельный helper;
- отчёт с предпросмотром, TXT, буфером обмена и Telegram-черновиком;
- импорт точной проверенной пары прежней русификации v3;
- документация, публичные Releases, Windows CI и независимый GUI-тест пути нового пользователя.

В конце передачи нет незавершённой исправляемой ошибки в проверенном сценарии. Основная установка владельца и её оригинальные копии сохранены; временные GUI-процессы испытания закрыты. Настройки/профили владельца не являются переносимыми данными приложения.

## Основные решения и причины

- Перевод сделан DOM-слоем в существующем изолированном preload, чтобы не менять бизнес-логику приложения. Узлы React сохраняются.
- Нативные тексты заменяются только при точном совпадении; неизвестные необязательные подписи пропускаются с записью в manifest.
- Совместимость не определяется только номером версии. Проверяются структура ASAR, имя пакета, preload и fuses. При неизвестном формате — отказ.
- `original.asar` неизменяем; `russian.asar` — производный кэш. Повреждение кэша не должно мешать откату целого оригинала.
- Самообновление — отдельная операция над EXE русификатора. Оно не перепатчивает Antigravity автоматически. Новые переводы применяются через «Вернуть оригинал» → «Русифицировать».
- Ничего не отправляется в Telegram автоматически. Bot token и вход в аккаунт Telegram не нужны.
- UI на русском; технические коды в отчёте остаются пригодными для диагностики.

## Проверки и фактические доказательства

Выпущенный код 1.1.0 находится в коммите `1658ce5927952b2095ef540a6e55ccd397195946`. Отчёт E2E добавлен в `5c752c1b58a0eab0eec0245927cf0999dbe2c781`. Новые коммиты передачи могут идти после них и не означают нового релиза EXE.

1. **50 автоматических проверок** прошли локально и в GitHub Actions. Они проверяют копирование, идемпотентность, откат, разные сборки, повреждения, фьюзы, поиск, отчёт, metadata, ZIP traversal и замену EXE/config с восстановлением при сбое.
2. **Самообновление** проверено на изолированной копии: helper дождался завершения родителя, заменил EXE, сохранил прежний файл и перезапустил приложение. Реальный ZIP 1.1.0 был затем загружен тем же UpdateService и проверен, без установки поверх рабочей копии.
3. **Новый пользователь** проверен опубликованным EXE с пустыми process-scoped USERPROFILE/APPDATA/LOCALAPPDATA. Автопоиск → копия → русификация → русский onboarding → защита от отката открытого приложения → закрытие → откат → английский onboarding. Все изменения выполнялись кнопками UI, SHA-256 сверялись отдельно.
4. Рабочие EXE, app.asar и прежние резервные копии владельца после E2E совпали с исходными хешами.

Полный протокол: `docs/TEST-REPORT-1.1.0.md`. Свежая Windows/отдельный ПК, браузерный Mark-of-the-Web/SmartScreen, Google login, региональный доступ и вызовы моделей в этом E2E не проверялись. Не расширяй вывод проверки за эти границы.

## Как безопасно продолжать

1. Прочитать CLAUDE.md, этот документ и git status. Не уничтожать посторонние изменения.
2. Выполнять следующую задачу владельца, а не автоматически весь список идей.
3. Перед изменением реальных файлов приложения сохранить и проверить текущие оригиналы; лучше сначала использовать синтетические тесты и локальную копию.
4. На Windows закрыть собираемый русификатор и выполнить Build.ps1 -Test. Не считать Linux-сборку/проверку текста эквивалентом пройденного GUI-теста.
5. При изменении ZIP согласовать имена/whitelist с UpdateService. Номер релиза — строго X.Y.Z, стабильный тег vX.Y.Z.
6. Публиковать релиз только после проверки соответствующего коммита; прикладывать ZIP и SHA-256, не перезаписывать опубликованные теги.

У владельца настроены GitHub CLI и доступ к origin на исходном компьютере, но перенос авторизации в архив не выполнялся. На другой машине Claude потребуется отдельный доступ владельца к GitHub для записи. Токены не запрашивать и не помещать в исходники.
