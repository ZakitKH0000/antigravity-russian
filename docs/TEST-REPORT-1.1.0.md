# Проверка пути нового пользователя — 1.1.0

Дата: 27 октября 2026 года. Результат: **пройдено, ошибок в проверенном пути не обнаружено**.

## Условия

Использовался ZIP **v1.1.0, скачанный из GitHub Releases**, а не локально собранный EXE. Зависимости дополнительно не устанавливались; запуск выполнен без повышения прав. На компьютере уже имеется .NET Framework 4.8.

Для дочерних процессов подготовлены отдельные пустые USERPROFILE, APPDATA и LOCALAPPDATA. Папки настроек и резервных копий русификатора в этом профиле отсутствовали. В стандартную папку установки внутри тестового профиля помещена копия настоящего Antigravity App 2.26.0, архив app.asar возвращён к сохранённому английскому оригиналу. Исходники обоих приложений для испытания не изменялись. Авторизация, переписка и настройки рабочего Antigravity в тестовый профиль не переносились.

Рабочий Antigravity был закрыт обычным способом, чтобы автопоиск работающего процесса не выбрал его вместо тестовой копии. После проверки рабочая установка снова открыта.

## Шаги и результаты

| Шаг пользователя | Наблюдаемый результат |
|---|---|
| Скачать и распаковать ZIP из Releases | Хеш совпал с опубликованным SHA-256, внутри EXE, конфигурация и документация |
| Запустить EXE | Окно открылось, установка 2.26.0 найдена автоматически, ручной выбор не понадобился |
| Посмотреть начальное состояние | «Готово к резервному копированию»; русификация и откат ещё недоступны |
| Нажать «Создать резервную копию» | Создана первая копия, её байты совпадают с оригиналом; установленный архив пока не изменён |
| Нажать «Русифицировать» | Состояние «Русский интерфейс установлен», архив совпадает с подготовленным русским файлом; оригинальная копия сохранена |
| Нажать «Открыть Antigravity» | Открылся экран первого запуска; заголовок «Решайте любые задачи с Antigravity», карточки и «Далее» на русском |
| Попробовать откат при открытом Antigravity | Понятная просьба закрыть приложение; никаких изменений в архиве, принудительного завершения нет |
| Закрыть Antigravity и нажать «Вернуть оригинал» | Оригинал 2.26.0 восстановлен, его SHA-256 точно совпадает с исходным |
| Снова открыть Antigravity | Тот же экран первого запуска на английском: «Get Anything Done with Antigravity», «Next» |
| Завершить тест | Рабочий установленный архив, EXE и ранее существовавшие резервные копии остались прежними |

Все действия копирования, русификации, запуска и отката выполнены **кнопками скачанного приложения через Windows UI**. Внешние команды использовались для подготовки изолированной копии и независимого сравнения SHA-256 после завершения операций.

## Границы проверки

- Это чистые данные приложений **на существующей Windows**, а не отдельная виртуальная машина, новая учётная запись Windows или компьютер другого пользователя.
- ZIP получен через GitHub CLI. Поведение браузерной метки загрузки, SmartScreen и антивирусов на другом ПК не проверялось. Сборка не имеет цифровой подписи издателя.
- Вход в Google, работа аккаунта в конкретном регионе и ответы моделей не проверялись: для испытания перевода достаточно экрана первого запуска, авторизация не требовалась.
- Вывод относится к Antigravity App 2.26.0 и русификатору 1.1.0. Совместимость другого варианта Antigravity, другой сборки или другой Windows требует отдельной проверки.

Для другого пользователя порядок остаётся обычным: распаковать ZIP → открыть EXE → создать копию → закрыть Antigravity → русифицировать. Если установка не найдена автоматически, доступен ручной выбор Antigravity.exe. Инструкция находится в [QUICKSTART.md](QUICKSTART.md).
