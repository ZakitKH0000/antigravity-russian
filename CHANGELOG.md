# Изменения

## 1.0.1 — 2026-10-27

- Повреждение подготовленного русского архива не блокирует откат из проверенного оригинала.
- Повреждённый производный архив автоматически пересобирается при повторной русификации.
- Добавлены две проверки восстановления после повреждения кэша.

## 1.0.0 — 2026-10-27

- Первое переносимое Windows-приложение с графическим интерфейсом.
- Выбор установки, отдельное резервное копирование, русификация, запуск Antigravity и откат.
- Словарь 2 653 записей для Antigravity App 2.26.0.
- Повторное применение после совместимых обновлений, отдельные копии каждой сборки.
- Перенос проверенной копии прежнего русификатора v3.
- Автоматические проверки и сборка в GitHub Actions.
