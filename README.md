# Antigravity Russian

Небольшое Windows-приложение для русификации **Antigravity App**: сохраняет оригинал, переводит интерфейс и возвращает английский язык при необходимости.

**[Скачать готовое приложение](https://github.com/ZakitKH0000/antigravity-russian/releases/latest)** · Windows 10/11 x64 · без установки · MIT

## Как пользоваться

1. Скачайте ZIP из Releases и распакуйте его в любую папку.
2. Откройте `AntigravityRussian.exe`. Обычно установка Antigravity находится автоматически. Если нет — нажмите **«Выбрать файл…»** и укажите установленный `Antigravity.exe`.
3. Нажмите **«Создать резервную копию»**.
4. Полностью закройте Antigravity, включая значок в трее, и нажмите **«Русифицировать»**.
5. Откройте Antigravity кнопкой в приложении.

Для отката закройте Antigravity и нажмите **«Вернуть оригинал»**. Для передачи брату или другу достаточно ZIP из Releases: ваши локальные резервные копии и настройки ему не нужны.

## После обновления Antigravity

Откройте русификатор снова. Он распознает новую сборку и предложит сохранить её собственный оригинал. После этого можно повторно применить словарь. Старый архив никогда не подставляется вместо новой версии; даже разные сборки с одинаковым номером версии имеют разные копии.

Совместимость проверяется по структуре пакета. При существенном изменении архитектуры инструмент откажется изменять установку. Новые строки разработчиков могут оставаться английскими до обновления словаря.

## Что поддерживается

- Antigravity **App**, Electron-вариант с `resources/app.asar`, Windows x64.
- Полный словарь из **2 653 записей** проверен на установленной сборке **2.26.0**.
- Другие сборки обрабатываются только при совместимой структуре; поддержка всех будущих версий заранее не гарантируется.
- Это не расширение для VS Code и не русификатор всех продуктов, называющихся Antigravity.

Требуется .NET Framework 4.8, входящий в современные Windows 10/11. Python, Node.js и SDK пользователю приложения не нужны. Для установки Antigravity в Program Files могут потребоваться права администратора; обычная установка в профиль пользователя работает без них. Готовая сборка пока не имеет цифровой подписи издателя.

## Резервные копии и данные

Копии хранятся на компьютере пользователя:

```text
%LOCALAPPDATA%\AntigravityRussian\backups\<установка>\<SHA-256 оригинала>\
  original.asar   — неизменяемый оригинал
  russian.asar    — подготовленная русская сборка
  manifest.json  — версия и контрольные суммы
```

Приложение изменяет только `resources/app.asar`. Чаты, проекты, авторизация, настройки моделей, исполняемые файлы и сетевые настройки не изменяются. Тексты сообщений, код, редакторы, терминальный вывод, названия файлов и значения полей ввода исключены из слоя перевода. Язык ответов модели задаётся отдельно.

Переводы встроены в EXE. Русификатор не обращается к сети и не содержит телеметрии. Ссылка «Проект на GitHub» открывается в браузере только по нажатию. Обновления самого Antigravity не отключаются. Фоновых служб и задач планировщика нет.

Для пользователей прежнего скрипта предусмотрен **«Импорт старой копии…»**. Сейчас поддерживается точная проверенная пара архивов русификации v3 для 2.26.0. Чужую неизвестную русификацию нужно сначала откатить её собственным инструментом.

## Сборка из исходников

На Windows 10/11 x64:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1 -Test
```

Результат: `bin/AntigravityRussian.exe` и конфигурация рядом с ним. Скрипт использует компилятор .NET Framework из Windows, без NuGet и сетевых загрузок. Также есть проект `AntigravityRussian.sln` для Visual Studio с установленным targeting pack .NET Framework 4.8.

Для запуска из локальной папки проекта можно дважды нажать `Start.cmd`.

Собрать переносимый ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Package.ps1
```

## Разработка

- `src/PatchService.cs` — обнаружение установки, копирование, русификация, откат, проверка процессов и миграция.
- `src/Archive.cs` — чтение, целостность и пересборка ASAR с сохранением остальных файлов.
- `src/MainForm.cs` — интерфейс WinForms.
- `payload/` — словарь, слой перевода DOM и правила подписей нативных диалогов.
- `tests/Tests.cs` — независимые синтетические архивы и проверки жизненного цикла, без настоящих бинарников Antigravity.
- `docs/ARCHITECTURE.md` — устройство и границы совместимости.

При исправлении словаря меняйте `payload/dictionary.json`, затем запускайте `Sync-Payload.ps1` и тесты. Оригинальные архивы, резервные копии, логи и личные настройки в Git не добавляются.

## Статус проекта

Текущая версия: **1.0.1**. Приложение и сценарии копирования/отката проверены локально; сборка и тесты запускаются также в GitHub Actions. Не прикладывайте токены, переписки, личные файлы или целые архивы установки.

Неофициальный проект; он не связан с Google и не изменяет доступность моделей, тарифы или региональные ограничения. Названия продуктов принадлежат их владельцам.
