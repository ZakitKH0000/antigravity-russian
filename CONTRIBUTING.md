# Участие в проекте

Для ошибки укажите версию Antigravity App, Windows и русификатора, ожидаемое поведение и текст ошибки. Прикладывая скриншот, скройте личную переписку, аккаунт и пути к личным файлам. Не загружайте настоящие `app.asar`, логи с перепиской или токены.

Для правки перевода отредактируйте `payload/dictionary.json` и выполните `Build.ps1 -Test` через Windows PowerShell 5.1. Слой перевода генерируется из `localize-ui.template.js`; не правьте сгенерированный файл отдельно.

Изменения в работе с архивами должны проверять побайтовый откат и сохранение остальных записей. Новая архитектура приложения должна приводить к безопасному отказу, пока для неё не подготовлена проверенная адаптация. Защиту подписи Electron и параметры безопасности отключать нельзя.

Исходники и переводы распространяются по MIT. Вклад принимается через pull request.
